# SMARTPROCURE — 5 MINUTE PRESENTATION

Good morning everyone.

Our project is SmartProcure — an Intelligent Farmer Procurement and Queue Management System.

The main problem we identified is that farmers often spend a lot of time waiting at procurement centres.

They may not know when their procurement slot is available, how long the queue will take, whether their procurement is completed, or when their payment will be processed.

To solve this problem, we developed SmartProcure.

Our system provides a complete digital journey from slot booking to payment.

First, the farmer logs into the application.

The farmer enters crop and quantity information and selects a procurement centre.

The system can recommend a suitable slot based on centre capacity, queue conditions and expected waiting time.

After booking, the farmer receives a digital token.

The farmer can then monitor the live queue instead of continuously waiting at the centre.

At the procurement centre, the operator manages the queue.

The operator can call the farmer, start processing and handle no-show cases.

The procurement process contains multiple digital stages.

First is quality inspection.

Then digital weighing is performed.

The system calculates the procurement amount based on the actual weight and applicable rate.

After procurement completion, the payment process is triggered and the farmer can view the payment status and digital receipt.

Our system also provides separate dashboards for operators, officers and administrators.

The officer dashboard provides operational visibility across procurement centres.

The administrator dashboard provides user, centre and audit management.

We have also integrated role-based access control so that each user can access only the functions appropriate to their role.

Another important feature is AI-based slot recommendation and queue intelligence.

The system can use queue and centre information to estimate waiting conditions and recommend suitable procurement slots.

For real-time communication, we use WebSocket technology for live queue updates.

Our frontend is developed using Flutter and Riverpod.

The backend is developed using Python FastAPI.

MySQL is used as the database and SQLAlchemy is used for database operations.

JWT authentication and role-based authorization are used for security.

Overall, SmartProcure aims to reduce unnecessary waiting, improve transparency, simplify procurement-centre operations and provide farmers with better visibility of their procurement and payment status.

Thank you.
