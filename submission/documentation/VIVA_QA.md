# SMARTPROCURE — VIVA QUESTIONS

## 1. What is SmartProcure?
SmartProcure is a digital farmer procurement and queue management system that manages slot booking, live queues, procurement, payment and administrative monitoring.

## 2. What problem does it solve?
It reduces unnecessary waiting and provides transparency about procurement schedules, queue position, procurement progress and payment.

## 3. Why Flutter?
Flutter allows us to build a modern cross-platform application using a single Dart codebase.

## 4. Why FastAPI?
FastAPI provides a lightweight, high-performance Python framework suitable for REST APIs and AI integration.

## 5. Why MySQL?
MySQL provides reliable relational data storage for users, bookings, queues, procurement and payment records.

## 6. What is JWT?
JWT is a token-based authentication mechanism used to securely identify authenticated users.

## 7. What is RBAC?
Role-Based Access Control restricts functionality according to user roles such as farmer, operator, officer and administrator.

## 8. Why WebSocket?
WebSocket provides persistent real-time communication, which is useful for live queue updates.

## 9. What is the AI component?
The AI component provides slot recommendations and queue/congestion intelligence using operational features such as queue size, processing time and centre capacity.

## 10. How is procurement calculated?
The system uses actual measured weight and the applicable procurement rate to calculate the gross amount and then applies applicable deductions to obtain the net payable amount.

## 11. What happens after procurement?
The system completes procurement, triggers or updates payment information and generates a digital receipt.

## 12. What makes the project useful?
It connects the farmer, procurement operator, officer and administrator in one digital workflow instead of handling each activity separately.

## 13. What is the future scope?
Government SMS/OTP, payment gateway integration, IoT weighing-machine integration, advanced forecasting and large-scale multi-district deployment.
